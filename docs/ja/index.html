長い講義も、安定した話し方で

手でスクロールせずに講義全体を読み切れます。話し方のキューを二重かっこで書いておくと、リマインダーとして表示されます。画面に残り、読み上げられることも単語として数えられることもありません。毎分の語数と残り時間はProで使えます。

Macのノッチの下に

ノッチのあるMacBookでは、パネルがそのすぐ下、カメラの近くに配置されるので、読みながら通話の相手を見られます。ノッチのないMacでは、パネルが画面上部の中央に表示されます。

よくある質問

声に合わせて進むプロンプターは、どのように動きますか？

Sightline Prompterは、読んでいる間に音声を聞き取り、聞こえた内容を画面上の単語と照合します。話すと文字が進み、止まると止まるので、スクロール速度ではなく話すペースで進められます。

声の追従はオフラインでも使えますか？

多くの言語は端末上で認識されるため、接続がなくても動作します。オフラインモデルが入っていない言語の場合、音声はAppleの音声サービスに送られ、アプリがその旨を画面に表示します。トルコ語を端末上で認識するには、iOSの音声入力モデルが必要です。

対応している言語は何ですか？

31の言語と地域差に対応しており、英語、ドイツ語、フランス語、スペイン語、イタリア語、ポルトガル語、日本語、韓国語、北京語、広東語、トルコ語などが含まれます。無料版は英語、トルコ語、スペイン語に対応しています。

ノッチのあるMacBookが必要ですか？

いいえ。ノッチのあるMacBookでは、パネルがそのすぐ下に配置されます。ノッチのないMacでは、パネルが画面上部の中央に表示されます。

文字サイズの自動調整はどう動きますか？

iPhoneでは、フロントカメラが顔と画面の距離を推定し、文字が同じ視角になるように大きさを調整します。その距離で読みやすい大きさになります。1行の長さと行数も抑えるので、視線がレンズの近くに残ります。Macでは、距離のプリセットを選ぶか、任意のカメラ測定をオンにします。測定はすべてお使いの端末の中で行われ、映像や顔のデータが端末の外に出ることはありません。

動画も録画できますか？

はい、iPhoneで録画できます。アプリはライブプレビューの上に原稿を浮かべたまま録画し、動画を写真ライブラリに保存します。Macアプリは、他のツールで行う通話や録画のためのプロンプターパネルです。

一度の購入でiPhoneとMacの両方を使えますか？

はい。App Storeでは一つのアプリで、Sightline Proを購入するとiPhone版とMac版の両方が使えるようになります。

どのファイルを取り込めますか？

プレーンテキスト、Markdown、Word、PDF、RTF、HTML、OpenDocumentファイルです。原稿はiCloudを通じてiPhoneとMacの間で同期されます。

ゲームコントローラーは使えますか？

はい。DualSenseコントローラーをBluetoothまたはUSBで接続すると、Macアプリで使えます。アナログスティックでスクロールし、ボタンで速度を変えたり段落を移動したりできます。コントローラーへの対応はSightline Proの機能です。

データはどう扱われますか？

原稿はお客様ご自身のiCloud Driveに保存されたままです。広告もアカウントもなく、アプリをまたいだ追跡も行いません。匿名の利用統計は設定でオフにできます。端末でのiCloudサインインが必要です。
